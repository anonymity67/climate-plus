# V4 water APIs

Prefix `/api/water`. Public reads use frozen sources; private checks use the authenticated owner. Responses are JSON with no-store/nosniff. Mutations require exact same Origin, JSON, a streamed 32 KiB body limit and server-side validation.

| Method/path               | Input                                                                                                                                                                                | Result                                                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| GET `/meta`               | None                                                                                                                                                                                 | Source dates/counts/types, presets, river names, stream areas and evidence gaps                                                            |
| GET `/sources`            | Required latitude/longitude; radiusKm .1–100, query≤200 chars, sourceType; integer offset≥0 and limit 1–100                                                                          | Result page, total, original fields, straight-line distances, source limitations                                                           |
| GET `/source?id=…`        | URL-encoded original WPdx ID                                                                                                                                                         | Source detail/checklist and nearby historical sites, qualified as proximity only                                                           |
| GET `/sites`              | Optional river/query                                                                                                                                                                 | Historical site summaries; no private records                                                                                              |
| GET `/site?id=site-N`     | Registered derived site ID                                                                                                                                                           | Original history, partial screening, nearest-channel match, connected sampled places within 5km and nearby inventory candidates within 2km |
| GET `/streams?area=dhaka` | dhaka/sylhet/dacope                                                                                                                                                                  | Frozen geometry/components/source; raw node arrays omitted from response but retained in source/bundle                                     |
| GET `/survey`             | None                                                                                                                                                                                 | Separately qualified BASIS velocity points/unlocated hydraulic means; not joined to quality stations                                       |
| POST `/rainwater`         | roofM2 1–10000, runoff .1–1, tankL 0–1000000, startL 0–tankL, dailyDemandL 1–100000, lossMm 0–20, rainfallMm array of 1–366 finite values 0–2000                                     | Echoed inputs, daily balance/totals, assumptions and server time                                                                           |
| GET `/checks`             | Sign-in; optional sourceId                                                                                                                                                           | Up to 100 most recent owner records                                                                                                        |
| POST `/checks`            | Sign-in; actual inventory sourceId, clientId 8–128 word/hyphen key, status needs-check/visited/unavailable/could-not-reach, valid non-future Bangladesh visitDate, note 1–1000 chars | Immutable private check and atomic creation audit; same key/payload returns original; different payload conflicts                          |
| GET `/checks-export`      | Sign-in                                                                                                                                                                              | Complete owner check history                                                                                                               |

Errors: 400 invalid input; 404 unknown record/area; 401 unauthenticated private access; 403 cross-origin mutation; 413 body too large; 415 non-JSON mutation; 409 conflicting retry. Internal errors expose a recovery message, not stack/database contents.

Retained `/api/observations` and `/api/cases` POST endpoints accept optional `clientId`, up to 128 letters/numbers/underscores/hyphens, unique per owner/resource. Measurements compare canonical content hashes; cases compare observation/title/note. Duplicate creation does not duplicate audit. Old clients without keys preserve prior append behavior. V4 supplies stable keys for manual/import/case retries, saving pending state locally to this tab. PATCH case updates retain revision protection.

Production actor identity comes from the trusted host, never the request body. The loopback preview adapter's Seedy cookie is development-only and is not production authentication.
